W25 binding protocol (clean-room, no peer source copied)
Attestation curve and CA: NIST P-256, native SHA256withECDSA, SEC1 uncompressed pub65, DER signatures. Each install RNG cardId16 and native non-exportable attestation keypair. Card ID is applet-instance id, not manufacturer chip serial. AID is fixed canonical installed applet AID (reject installing under different instance AID if practical).
All applets INS 0x70 GET_ATTESTATION_INFO (empty); 0x71 STORE_ATTESTATION_CERT (DER CA sig 8..72); 0x72 GET_ATTESTATION (challenge32); 0x73 SEAL_ATTESTATION (empty); 0x74 GET_KEY_BINDING (empty). Existing CLA: ETH2/vault 80, MuSig2 00; require P1/P2=0.
INFO bytes: version01 || cardId16 || aidLength1 || aid || attestationPub65 || sealed1 || certLength1 || certDER. GET_ATTESTATION bytes: INFO || signingPubLength1 || canonicalSigningPub || pinState1 || responseSigLength1 || responseSigDER || bindingSigLength1 || bindingSigDER. All length bytes unsigned. signingPub = compressed secp256k1 pub33 for ETH2/MuSig2, uncompressed P256 pub65 for vault; zero length before KEYGEN. pinState bits: 0 mandatory policy, 1 PIN configured, 2 PIN validated, 3 blocked.
CA message ASCII NURI-ATT-V1 || cardId16 || AID || attestationPub65. Response message ASCII NURI-ATT-RESP-V1 || challenge32 || signingPub || pinState1. NHWV1 message ASCII NHWV1 || AID || signingPub. Standard SHA256 ECDSA (not prehash API) on all these full messages. Responses must not expose private key scalar. Cert write-once in transaction, refused when sealed or already stored. SEAL requires cert present; irreversible transaction. No other operation can clear it. GET_KEY_BINDING returns DER only, requires keyed; same NHWV1 generated during keygen, survives reset.
Helper class NuriAttestation, duplicated per applet package from shared canonical implementation (parent owns card/attestation/NuriAttestation.java.in and generation): constructor(byte[] aid); boolean handles(byte ins); void process(APDU apdu, byte[] signingPub, short off, short len, byte pinState); void prepareBinding(byte[] pub, short off, short len) before caller key transaction; void commitBinding() INSIDE same caller key+cache+keyed flag transaction; void clearScratch() every command exit. No signing-public export on uncommitted flag. Helper output uses own transient array and sendBytesLong, >256 supported by PCSC procedure handling. prepareBinding must finish BEFORE master key publication; commitBinding copies transient candidate sig atomically. clearScratch never erases published state. Helper owns independent scratch, no master key access.
